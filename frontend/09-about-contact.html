Project fundamentals

What powers this PawAI project.

Frontend

Responsive HTML, CSS, and browser JavaScript pages share a centralized API and theme helper. User interface preferences are stored locally; authentication data is not.

Backend API

FastAPI provides the authentication, pet, and contact endpoints. Pydantic validates incoming form data and SQLAlchemy connects the application to PostgreSQL.

Sessions & security

Passwords use Argon2id hashing. Authentication uses opaque, server-side sessions in HttpOnly cookies, with CORS credentials enabled for local development.

Data & migrations

PostgreSQL stores users, pets, and sessions. Alembic manages the initial database schema migration. Contact delivery is configured only through backend environment variables.
